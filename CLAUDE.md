# Boondock Walker — site notes for Claude

## Voice & tone

The bureau's voice is **conversational and approachable**.

- Avoid copy that reads as **clinical** (label-y, terse fragments, "Our X practice.").
- Avoid copy that reads as **punchy / manifesto** (staccato three-fragment riffs, dry rhetorical contrasts).
- Write in full sentences with natural rhythm. Let ideas breathe.
- Confident but warm. Specific without sounding like a brochure.
- We can be witty, but never hard-sell or dramatic.
- When tempted to write a one-line zinger, ask whether a fuller sentence would land more honestly.

If a draft sounds like it could be on the back of a B2B brochure or in a startup manifesto, rewrite it.

## House terminology

- The firm is a **bureau**, not an agency.
- "Bench" refers only to the team — never use as a metaphor for catalog/sandbox.
- Email everywhere: **hello@boondockwalker.com**.
- Don't quantify engagements (avoid "X engagements since 2015"). "12 selected cases" / "12 featured cases" is fine.
- **Vesper** is an *AI-guided brand foundation builder* (a tool/app). It is not itself a brand foundation.
